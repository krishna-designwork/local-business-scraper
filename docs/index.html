🗺️ Maps Scraper

A multi-worker Google Maps business scraper with a desktop GUI. No proxies, no paid APIs — collects business data at scale into CSV and SQLite.

Python 3.10+Windows & macOSMIT LicensePlaywright + CustomTkinter
⬇ Download (.zip) View Code on GitHub
Heads-up: this is a desktop application — it runs on your computer and drives real Chrome windows (that's how it avoids Google's bot detection). It can't run inside a web page; download it and run it locally.

Features

⚡ Up to 20 parallel workers

Each with its own browser profile and isolated location queue.

🥷 Anti-detection built in

Human-like mouse movement, gaussian delays, fingerprint masking, CAPTCHA cooldowns.

🔁 Resumable

Already-scraped places are skipped on re-runs via a SQLite dedup database.

🎛️ Filters

Review count, rating, must/must-not have website or phone — applied before writing.

📍 Bulk locations

Import a CSV of cities or add them manually as chips in the GUI.

📊 Dual output

Excel-friendly CSV per run plus a SQLite database per keyword.

Quick start

git clone https://github.com/krishna-designwork/local-business-scraper.git
cd local-business-scraper
pip install -r requirements.txt
playwright install chromium
python gui.py

How it works

  1. Enter a search keyword (e.g. "dentist") and add locations
  2. Pick results per location, parallel workers, and optional filters
  3. Hit Start — real Chromium windows scrape Google Maps with human-like behavior
  4. Grab your CSV from the outputs/ folder

Output columns

keyword, location, city, state, country, name, category, address,
phone, website, website_type, rating, review_count, hours, schedule,
latitude, longitude, place_url, scraped_at, reviews
